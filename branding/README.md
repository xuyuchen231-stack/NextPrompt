# NextPrompt 品牌资源

采用深海军蓝与薄荷绿，一条折带组成 N，并在右上方形成向前的箭头，表达“下一步接上当前工作”。

- `nextprompt-logo.webp`：1024 × 1024 品牌图。
- `../extension/assets/logo.webp`：256 × 256 界面资源。
- `../extension/icons/`：16、48、128 像素扩展图标。

图像由内置图像生成工具创建。项目中的派生资源仅调整尺寸与编码，没有重新绘制或改变图案。原始生成图已在对话中展示。

Deep ink navy rounded-square tile, luminous mint/seafoam ribbon with very restrained dimensional shading, nearly flat clean geometric silhouette. Sophisticated modern productivity software identity, quiet, confident, precise. Center the symbol, generous consistent margins, occupies about 68% of the tile. Crisp edges, excellent recognition when reduced to 32 pixels. No lettering, no wordmark, no slogans, no extra symbols, no stars, no sparkles, no robot, no speech bubble, no mockup, no border outside tile, no watermark. The icon itself fills the square canvas; background deep navy, not a presentation sheet.
