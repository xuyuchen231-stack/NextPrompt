NextPrompt v1.3 — Chrome / Edge 安装与使用

一、安装（无需开发环境或 API Key）
1. 将下载的 nextprompt-v1.3.0.zip 解压到固定位置。
2. Chrome 打开 chrome://extensions；Edge 打开 edge://extensions。
3. 打开“开发者模式”或“开发人员模式”。
4. 点击“加载已解压的扩展程序”或“加载解压缩的扩展”。
5. 选择解压出来的 nextprompt 文件夹。该文件夹内直接包含 manifest.json。
6. 打开或刷新 https://chatgpt.com 中一个已有消息的对话。
7. 点击右下角“下一步”，或将 NextPrompt 固定到浏览器工具栏。

如果下载的是 GitHub 源码 ZIP，第 5 步选择其中的 extension 文件夹。
这不是商店签名安装包；不能通过双击 ZIP 安装。当前版本面向桌面 Chrome / Edge。

二、立即补充（最简单的使用方式）
1. 在 ChatGPT 原生输入框写好要补充的内容，按需附上文件并等待上传完成。
2. 在 NextPrompt 工作台点击“立即补充当前任务”。
3. 不需要结束口令。扩展只点击可用的原生发送按钮，不点击停止按钮。
4. 网页可能将新消息加入当前任务，也可能排入原生队列，取决于网页当前设置。

三、完成后发送（可选）
1. 在开始本轮任务之前，点击“生成并复制本轮结束约定”。
2. 将复制的内容附在本轮任务提示词末尾一并发送。
3. 准备下一条原生草稿，点击“本轮结束后发送当前草稿”。
4. 扩展等待匹配的本轮口令与稳定状态后发送。没有约定的旧任务不会自动猜测完成。
5. 多条纯文字后续任务可放在“任务队列”，再点击“启动队列”。

四、更新与核验
更新文件后，在扩展管理页点击重新加载，再刷新 ChatGPT 页面。
刷新后自动发送默认暂停。若显示待核验，请检查聊天记录和网页原生队列；结果不明时不会自动重试。
