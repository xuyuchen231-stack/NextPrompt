# v1.2 任务工作台

## 三个页面

| 页面 | 内容 |
| --- | --- |
| 工作台 | 当前对话、运行状态、队列数量、连续确认时间、结束约定和原生草稿发送 |
| 任务队列 | 添加文字任务、搜索、排序、编辑保存／取消、启动队列 |
| 设置 | 连续确认时间、任务导入导出、无正文诊断、运行记录、待核验发送解锁 |

状态卡和底部暂停按钮在三个页面均可见。对话标题仅显示在当前面板内，不通过网络传输。

## 侧栏和浮窗

默认使用固定在网页右侧的工作台，点击顶部布局按钮切换为浮窗。布局偏好保存于当前浏览器配置；刷新后保留布局，但自动发送仍不会恢复。

这里是扩展注入 ChatGPT 页面的侧栏，不是浏览器原生 Side Panel API。未新增 `sidePanel`、`tabs` 或额外网站权限。面板不会改写 ChatGPT 页面布局；需要查看被覆盖的区域时可收起面板或切换浮窗。

窄窗口下，面板自动留出左右边距并在内部滚动，底部暂停按钮保持可见。主要面向桌面 Chrome / Edge，响应式布局不代表手机浏览器支持安装扩展。

## 交互

- 点击三个导航标签切换页面；标签获得焦点时可用左右方向键、Home、End 切换。
- 在任务输入框按 Ctrl + Enter（macOS 为 Command + Enter）加入队列。
- 队列搜索仅过滤展示，不改变任务顺序，也不影响导出内容。
- 编辑在原卡片内进行：保存后替换原任务正文，取消则保留原文和位置。编辑未完成前不允许启动自动发送。
- 有限的任务卡内滚动用于长文本；主面板也可滚动。
- 在面板内按 Escape 收起；工具栏按钮或 Alt + Shift + Q 可重新打开。
- 收起不等于暂停；底部“暂停全部自动发送”才停止后续自动点击。
