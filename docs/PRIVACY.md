# 隐私说明

NextPrompt v1.2 没有外部数据服务、遥测、广告或模型 API 调用。

为完成用户启用的任务，扩展在 ChatGPT 页面读取当前输入框、可见对话、附件组件状态和操作按钮。已排队任务、最多 100 个未消费的随机结束口令和最多 50 条操作日志存储于当前浏览器的本地扩展存储。已发送队列项移除，正文不保留在发送日志中。

原生草稿和附件由 ChatGPT 页面处理，扩展不下载或复制附件文件。后台租约服务仅接收对话路径，使用会话存储协调同一浏览器配置的标签页。

任务导出包含任务正文，不包含整个对话或附件。诊断复制只输出布尔状态、版本和运行模式，不含正文、文件名或对话 ID。

删除扩展会由浏览器处理扩展存储清理；导出的 JSON 文件需要用户自行管理。扩展存储没有额外加密，任何有权访问浏览器配置的人可能取得其中内容。

消息发送到 ChatGPT 后，适用 ChatGPT 自身的数据处理规则。本项目不是 OpenAI 官方产品。

界面布局偏好保存在浏览器本地。显示的当前对话标题仅在本页面使用。Logo 从扩展自身资源加载，不访问第三方图片服务。
